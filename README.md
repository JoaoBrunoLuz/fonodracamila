# Landing Page - Clínica de Fonoaudiologia Dra. Camila

Esta é uma Landing Page moderna, responsiva e acolhedora desenvolvida para uma clínica de fonoaudiologia. O foco do design é transmitir confiança e profissionalismo através de uma estética clean e tons suaves.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estrutura semântica.
- **Tailwind CSS**: Estilização moderna e responsiva via CDN.
- **Lucide Icons**: Conjunto de ícones vetoriais elegantes.
- **Google Fonts (Outfit)**: Tipografia legível e profissional.

## 📋 Seções da Página

- **Hero**: Introdução com mensagem de impacto e chamada para ação (CTA).
- **Serviços**: Detalhamento das áreas de atuação (Linguagem Infantil, Voz Profissional, Reabilitação Auditiva).
- **Sobre**: Biografia da profissional com foco em atendimento humanizado.
- **Depoimentos**: Prova social com feedback de pacientes reais/fictícios.
- **Rodapé**: Informações de contato, localização e links para redes sociais.

## 🛠️ Como Visualizar o Projeto

1. Clone este repositório:
   ```bash
   git clone https://github.com/JoaoBrunoLuz/fonodracamila.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador moderno.

## 🎨 Design

O projeto utiliza uma paleta de cores baseada em tons de azul claro (`#e0f2fe`) e branco, com animações suaves de entrada para uma experiência de usuário (UX) fluida.
